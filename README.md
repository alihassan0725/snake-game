# 🐍 Snake Game

A simple and classic **Snake Game** developed in **C++**. The player controls the snake, eats food to increase the score, and tries to avoid hitting the walls or the snake's own body.

## 🎮 Features

- 🐍 Classic Snake gameplay
- 🍎 Food generation
- 📈 Score tracking
- 💀 Game Over system
- ⌨️ Keyboard controls
- 🔄 Restartable gameplay
- 🖥️ Console-based interface

## 🛠️ Technologies Used

- **C++**
- **C++ Standard Library**
- Console Input/Output
- Loops and Conditional Statements
- Functions
- Arrays / Variables

## 🎯 How to Play

Use the following keys to control the snake:

| Key | Action |
|---|---|
| `W` | Move Up ⬆️ |
| `S` | Move Down ⬇️ |
| `A` | Move Left ⬅️ |
| `D` | Move Right ➡️ |

### Rules

1. Control the snake using the keyboard.
2. Eat the food 🍎 to increase your score.
3. The snake grows after eating food.
4. Avoid hitting the walls.
5. Avoid hitting the snake's own body.
6. The game ends when the snake crashes.
